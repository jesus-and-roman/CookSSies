N'importe quel site HTML

Le bandeau apparaît automatiquement en bas de la page tant que l'utilisateur n'a pas fait de choix (choix retenu 180 jours via cookie).

Intégration minimale — une seule ligne avant la fermeture de </body> :

<script src="cookie-consent.js" defer></script>

Personnalisation optionnelle (couleurs, textes, durée du cookie) — à mettre AVANT le script :

<script>
  window.CookieConsentConfig = {
    cookieDays: 365,
    theme: { accent: "#4a90c9", bg: "#111" },
    locale: { title: "Vos cookies, vos règles" }
  };
</script>
<script src="cookie-consent.js" defer></script>

Écoute des choix pour activer/désactiver tes propres scripts (analytics, etc.) :

window.addEventListener('cookieConsentUpdated', (e) => {
  if (e.detail.analytics) {
    // charger ton script analytics ici
  }
});
