Consentement Plus de données Supabase

Données collectées maintenant (si analytics accepté) :

  • session_id anonyme
  • URL + path + titre + referrer
  • navigateur, OS, type d’appareil
  • langue(s), timezone
  • résolution écran + viewport + DPR
  • hardwareConcurrency, maxTouchPoints
  • cookieEnabled, doNotTrack, online
  • préférence dark mode
  • type de connexion (4g/3g…), downlink, RTT
  • temps de chargement + metrics performance
  • clics (texte du bouton/lien + position x/y)
  • profondeur de scroll max
  • temps passé + heartbeats
  • option masquer IP (jamais d’IP complète côté client)
