Démo — Bandeau cookies + Tracker

Le bandeau apparaît en bas tant que tu n’as pas choisi. Les données analytics ne partent que si tu acceptes la catégorie Analytiques.

Consentement Analytics raisonnable Supabase ready

Ce qui est collecté (si analytics = true)
• pageview (URL, titre, referrer)
• temps passé sur la page + heartbeat
• appareil / navigateur / OS / résolution / langue / timezone
• clics sur liens et boutons (texte + position approximative)
• profondeur de scroll max
• session_id anonyme
• option « masquer IP » (jamais d’IP complète côté client)

Exemple de ce qui part dans Supabase
